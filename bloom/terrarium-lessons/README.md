# Terrarium Lessons

**Style:** Bhakta at the Door setting, with Radiant warmth
**Status:** Living
**Room:** vision

---

Terrarium is the native macOS application that puts Grain's entire system
on your screen -- a living world under glass. These tutorials walk through
each part of the application, from launching it for the first time to
reading the financial ledger and querying the event log.

## Tutorials

- [Launching the App](launching-the-app.md) -- What you see when
  Terrarium opens, how it finds the project, and what "building" means
- [The Terminal Tab](the-terminal-tab.md) -- Running RISC-V code on your
  Mac through QEMU, watching witnesses prove themselves
- [The Dimeroll Dashboard](the-dimeroll-dashboard.md) -- Reading the
  financial ledger: transactions, inventory, and cash flow
- [Queries and Mantra](queries-and-mantra.md) -- Asking the records a
  question, and understanding the append-only event log
- [The Bloom Tab](the-bloom-tab.md) -- Navigating curriculum, ecology,
  guides, demos, and essays inside Terrarium

## How to read these

Start with "Launching the App" and work through in order. Each tutorial
builds on the one before it. By the end, you will know how to use every
tab in Terrarium and understand what each one shows you.
