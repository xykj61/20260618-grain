# Grain Lineage Teachings

**Style:** Bhakta at the Door setting, with Radiant warmth

These seven teachings explore the design principles that shaped Grain as
an operating system. Each one takes an idea from Grain's own lineage --
the research and vision that came before the code -- and restates it in
plain language, using the names of the modules you have already met in
the curriculum.

You do not need to read these in order, though they build on each other
gently. Start with whichever title catches your eye.

## The seven teachings

| Teaching | What it explores |
|----------|-----------------|
| [Dual description](dual-description.md) | The same system seen from two sides at once |
| [One carrier, many flows](one-carrier-many-flows.md) | Running many purposes through a single shared spine |
| [The state at the center](state-at-center.md) | Building an entire computer around one pure function |
| [The whole in every part](whole-in-every-part.md) | How local agreement becomes global consistency |
| [Bounded optimization](toroidal-bounded-optimization.md) | Tuning a system that has hard limits, wisely |
| [The shape of a computer](silicon-torus-hardware.md) | What happens when you ask what shape memory wants to be |
| [The place and its patterns](the-place-and-its-patterns.md) | A system IS its data, and faithful transformations carry the substance |

## Where they come from

Each teaching draws its substance from a design study in
`external-research/grain-lineage-silo/`, which itself siloed the
engineering core from the visionary originals held in `gratitude/grain-lineage/`.
The originals are kept whole and honored; these teachings carry only the
part a newcomer can put to work.

May these seven ideas land as clearly as the curriculum that walks beside them.
