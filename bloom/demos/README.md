The demos shelf puts Grain's network layers into practice using a
fourteen-galaxy test network called a Puddle. Each galaxy is a
placeholder -- named for a garden plant, and deliberately shaped so
that no command copied from these pages can ever reach a real ship on
the live Urbit network.

## The fourteen galaxies

Every demo on this shelf uses the same fourteen galaxies. Each is
named for a plant that belongs in a biocyclic vegan garden:

`~sunflower` -- `~rosemary` -- `~lavender` -- `~basil` --
`~chamomile` -- `~oregano` -- `~thyme` -- `~sage` -- `~mint` --
`~fennel` -- `~marjoram` -- `~tarragon` -- `~chive` -- `~dill`

These names are four to nine letters long. A real Urbit galaxy name is
exactly three letters. The mismatch is on purpose: a name that cannot
parse as a real address cannot accidentally reach a real machine,
however literally a newcomer copies it.
